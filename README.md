# 🎓 Atomcamp Adaptive Learning Management System (LMS)

## 📌 Project Overview

This is a **Smart Adaptive Learning Management System** built for **atomcamp** - an emerging tech education ecosystem in Pakistan. The system personalizes each student's learning journey, provides real-time feedback, and gives instructors actionable intelligence to improve outcomes at scale.

## 🚀 Features

### For Students 👨‍🎓
- **Personalized Onboarding** - Select your career goal and skill level
- **Course Selection** - Choose individual courses from recommendations
- **Quiz System** - Take quizzes and get immediate feedback
- **Progress Tracking** - See your overall progress percentage
- **View Lecturer Feedback** - See comments and recommendations from lecturers

### For Instructors 👨‍🏫
- **Class Progress Dashboard** - View overall class performance
- **At-Risk Student Detection** - Identify students struggling (scores < 60%)
- **Add Comments** - Write personalized comments for students
- **Add Recommendations** - Give specific advice to help students improve
- **Module Performance** - See how students perform on each module

### For Admins 👑
- **Student Management** - View, edit, or delete student profiles
- **Course Management** - Add new courses with custom modules
- **Remove Courses** - Delete existing courses
- **System Statistics** - View total students, courses, and class progress
